# Online Retail Data Analysis Using Microsoft Excel

## Project Overview
This project focuses on analyzing an online retail dataset using Microsoft Excel to identify sales trends, product performance, customer purchasing patterns, and transaction-related insights.

The analysis transforms raw transactional data into meaningful business insights through data cleaning, data profiling, Excel formulas, PivotTables, and an interactive dashboard.

## Dataset
- **Source:** UCI Machine Learning Repository
- **Dataset:** Online Retail
- **Records:** 541,909
- **Period:** December 2010 – December 2011
- **Country:** United Kingdom and other international markets

Dataset source: https://archive.ics.uci.edu/dataset/352/online+retail

## Tools and Techniques
- Microsoft Excel
- Excel Tables
- Data Cleaning and Preparation
- Data Profiling
- Calculated Columns and Formulas
- PivotTables
- Charts and Dashboard
- Business Insights and Recommendations

## Project Structure
1. Raw_Data – Original dataset.
2. Data_Profiling – Data quality assessment.
3. Working_Data – Prepared dataset with calculated columns.
4. Analysis – Key metrics and calculations.
5. Pivot_Tables – Detailed analytical summaries.
6. Dashboard – Visual representation of key performance indicators.
7. Business_Insights – Findings from the analysis.
8. Business_Recommendations – Suggested business actions.

## Key Business Insights
- Regency Cakestand 3 Tier (StockCode 22423) generated the highest product revenue.
- The United Kingdom was the leading market by revenue.
- November 2011 recorded the highest monthly sales.
- CustomerID 14646 was the highest-revenue identified customer.
- Cancellation records represented approximately 1.71% of all transaction records.
- Missing CustomerIDs accounted for approximately 24.93% of records.

## Dashboard Highlights
The dashboard presents:
- Gross Sales Revenue
- Total Records
- Regular Transaction Records
- Cancellation Rate
- Monthly Sales Trend
- Monthly Cancellation Trend
- Top 10 Products by Sales
- Top 5 Countries by Sales

## Data Preparation
The project preserves the original dataset and adds calculated fields to support analysis:
- Revenue
- Transaction Type
- Customer Status
- Price Status

Records with missing CustomerIDs were retained for overall transaction analysis and excluded from customer-level analysis.

## Project Objective
The objective is to demonstrate practical Excel data analytics skills, convert raw retail data into useful information, and provide actionable business recommendations.
